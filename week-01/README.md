# FortisCode Global LLC – Training Repository

## 📅 Semana 1 – Fundamentos y Configuración

### 🎯 Objetivo
Realizar una inmersión inicial en la cultura, estándares técnicos y entorno de trabajo de FortisCode Global LLC, asegurando que la estación de trabajo cumpla con los requisitos de seguridad, versionado y buenas prácticas de ingeniería.

---

## 🧭 Metas Cumplidas

- **Alineación Operativa**
  - Lectura y comprensión del:
    - Manual de Vuelo (Cultura y Comunicación)
    - Playbook Técnico (Estándares de Ingeniería)
    - Guía de Setup y Seguridad
- **Preparación del Entorno**
  - Configuración del stack tecnológico base en entorno Linux/WSL
  - Verificación de versiones y herramientas críticas
  - Activación de medidas de seguridad (2FA y GPG)
- **Inmersión en Proyectos**
  - Revisión de pliegos de proyectos activos
  - Análisis del contexto regional (Bolivia, Chile, Perú)
- **Repositorio de Entrenamiento**
  - Creación y estructuración del repositorio personal
  - Aplicación de estándares de documentación y versionado

---

## 🛠️ Actividades Realizadas

### 📘 Estudio de Documentación
Se realizó la lectura completa de los documentos base, comprendiendo el **porqué** de las herramientas, flujos de trabajo y decisiones técnicas adoptadas por FortisCode Global LLC.

### 📄 Análisis de Pliegos
Revisión de los requerimientos técnicos y objetivos de los proyectos asignados, identificando:
- Problemas a resolver
- Contexto operativo
- Impacto regional de las soluciones

### ⚙️ Configuración Técnica
- Verificación de versiones de herramientas clave
- Configuración segura del entorno de desarrollo
- Validación de prácticas de seguridad requeridas

### 📂 Espacio de Aprendizaje
Este repositorio será utilizado para:
- Ejercicios de código
- Pruebas de arquitectura
- Tareas de nivelación técnica
- Evidencias de aprendizaje semanal
